# Прототип

[`index.html`](index.html) — самостоятельная HTML-страница без сборки. Откройте файл в браузере. Панель сверху переключает состояния: страница открыта, ошибка ввода, загрузка, отчёт, нет отчёта, неделя ещё идёт, ошибка сервера. На каждое состояние можно дать ссылку: `index.html#form`, `#invalid`, `#loading`, `#success`, `#empty`, `#current`, `#error`.

Скриншоты всех состояний на десктопе (1280px) и телефоне (390px) лежат в [`screenshots/`](screenshots). Их снимает `node scripts/capture-screenshots.mjs`.

## Что предложил ИИ

Прототип сделан Claude Code (Opus 5.5) по брифу Lab 8 с подсказками скилла `frontend-design`. Сначала ИИ составил план дизайна, потом сверстал страницу.

- **Предмет:** недельный учёт задач одного репозитория. Пользователи — автор курса и проверяющий. Главная задача — за пару секунд увидеть, сколько задач создали и закрыли за неделю.
- **Главный акцент:** полоса из семи дней под заголовком результата, выбранный понедельник выделен. Это самое узнаваемое в теме «неделя». Остальная страница спокойная.
- **Цвет:** холодная серо-голубая «бумага» `#f4f6f9`, сине-чёрный текст `#17202c`, один акцент `#2a4fcf`. Цвета четырёх метрик: создано — синий, закрыто — оранжевый, открыто — зелёный, в работе — янтарный. Палитра проверена скриптом скилла `dataviz` на различимость, в том числе при дальтонизме. В таблицах цвета появляются только точками у подписей, в «Последних неделях» — полосками.
- **Шрифт:** один, Onest — с кириллицей, моноширинные цифры для столбцов.
- **Что ИИ отбросил при самопроверке плана:** кремовый фон с антиквой и тёмную тему с кислотным акцентом (шаблонные решения), отдельные плитки KPI «большое число + подпись» (итог уже есть в строке «Всего»), а также нумерацию и надписи капслоком.

## Что изменено после ревью

Прототип правили вместе с интерфейсом, чтобы они совпадали:

1. Кнопка переехала в одну строку с полем, а ошибка и подсказка — под эту строку. В первом варианте ошибка ужималась в ширину поля и занимала три строки.
2. Ошибка ввода стоит над подсказкой: её важнее увидеть первой.
3. В таблицу типов добавлены метки GitHub (`bug`, `task`, `feature`). Так видно, по какой метке считается строка. На телефоне метки скрыты, чтобы таблица помещалась.
4. В пустом состоянии указана неделя, которой нет, и добавлена иконка. Текст ошибки совпадает с интерфейсом.
5. Исправлена навигация по `#состоянию`: раньше смена хэша без перезагрузки не меняла экран.

## Второй раунд

После отзыва автора («почему именно понедельник?») прототип перерисован вместе с интерфейсом:

1. Поле «Любой день нужной недели» с подсказкой, какая неделя будет показана. Кнопки быстрого выбора «Прошлая неделя» и «Позапрошлая неделя».
2. Заголовок недели со стрелками «Предыдущая» и «Следующая». В полосе недели выделен выбранный день, а не всегда понедельник.
3. Новое состояние «Неделя ещё идёт» с кнопкой «Открыть прошлую неделю».
4. Блок «Последние недели»: переключатель 4, 8 или 12 недель, легенда, полоски «Создано» и «Закрыто», недели без отчёта отмечены. На телефоне полоски под названием недели.
5. В ошибке сервера сообщение и подсказка про повтор — два отдельных предложения.
6. Фиолетовый у «Закрыто» заменён на оранжевый: проверка палитры показала, что синий и фиолетовый сливаются при протанопии.
